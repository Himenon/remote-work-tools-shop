アイランド Hydration（CSR）

ブラウザ受信
  • SSR済み HTML
  • /static/client.js を非同期ロード
→
client.js（アイランド）
  • DarkModeToggle
  • BuyFormConnector
  • CheckoutFormConnector
→
React hydration
  • 既存 DOM に React イベントをアタッチ
  • 追加の HTML レンダリングは不要
  • インタラクティブ部分のみ CSR

HonoX のアイランドアーキテクチャ: ページ全体を SPA にせず、インタラクティブなコンポーネントだけを React hydration する。初期 HTML は SSR で生成済みのため FCP が速い。

現状構成 vs CDN 分離

現状: Hono が静的ファイルも配信
  • 構成がシンプル（1プロセス）
  • serveStatic が Node.js のファイルI/Oで配信
  • 静的ファイルのスケールは Node.js に依存
CDN 分離時: /static/* を CDN にオフロード
  • dist/static/ を CDN オリジンに配置
  • CDN が /static/* を edge から配信
  • Hono サーバーは SSR・API のみ処理
  • assets/[hash].js は immutable キャッシュ可
